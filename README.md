## Current Prototype Direction

The revised prototype should focus on MUMOSA as an interactive multimodal Q/A workspace for post-crisis investigation:

1. Select an incident and timeframe.
2. Ask a natural-language question.
3. Inspect the answer with textual and visual evidence.
4. Compare sources, confidence, and discrepancies.
5. Build a trusted timeline and schema-backed event map.
6. Use simulation/VR as an optional spatial evidence mode.

The strongest critique target is the timeline/schema view. It should clearly show event relationships, source links, evidence confidence, and discrepancies rather than acting as a detached graph. The detailed revision plan is in `02_Digital_Prototype/Revised_Figma_Dashboard_Plan.md`.
