# Prototype Media Library

This folder stores substitute media for the MUMOSA Unreal spatial review prototype.

The prototype does not use official MUMOSA system media. Instead, it uses representative public-domain, government, Creative Commons, or otherwise permission-compatible media to simulate the kinds of evidence MUMOSA might connect to a reconstructed scene.

## Important Label

Use this wording in docs or UI when showing these assets:

```text
Representative source evidence
Used for educational prototype purposes. Not official MUMOSA system data.
```

Alternative wording:

```text
Prototype source footage
Public-domain/government reference media used to simulate MUMOSA evidence inputs.
```

## Folder Guide

### source_photos

Original downloaded photos used as evidence references.

### source_video

Original downloaded or linked video references.

### processed_stills

Frames extracted from video or edited/cropped versions used in the prototype UI.

### reference_links

Text files or notes containing source URLs that have not yet been downloaded.

### licenses_and_attribution

Usage notes, attribution text, and license screenshots/records where needed.

## Preferred Source Types

Use government/public-domain-style sources first:

- EPA East Palestine photos.
- NTSB b-roll or public media.
- FEMA Media Library.
- DVIDS public-domain media.
- DHS public-domain media.

Use Creative Commons or stock sources only when government sources are insufficient.

## Unreal Usage

Media should appear as source evidence, not as the product itself.

Use media as:

- Source thumbnails in the evidence panel.
- Clickable video/source screens.
- Bodycam or drone position markers.
- Timeline-linked snapshots.
- Confidence/discrepancy references.
- Visual proof for AI-labeled scene markers.
